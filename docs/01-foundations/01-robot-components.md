# 1. 一台 ROS 机器人由什么组成

## 本章要回答的问题

一台轮式机器人为什么既有轮子、电机和电池，又有两块甚至更多电路板？这些部件分别负责感知、计算和运动中的哪一步？

本章先看实物，不开机，也不运行命令。读完后，你应该能指出机器人的主要部件，并说清主控与控制板为什么不能互相替代。

## 从一个具体场景开始

把一台轮式机器人放在桌面上。外面最容易看到的是车架、轮子和传感器；打开上盖后，通常还能看到电池、电机驱动、电路板和许多线缆。

假设机器人要完成一个简单任务：发现前方有障碍物，然后停下来。整个过程可以先写成一句普通话：

```text
传感器看见环境 → 主控里的程序作出决定 → 控制板按周期驱动电机 → 轮子运动
```

这条链路中的每一部分都不可缺少。传感器没有数据，程序就不知道前面有什么；程序没有作出决定，底层电路也不知道应该怎样调整电机；电机和供电出问题，即使程序判断正确，机器人仍然不会运动。

## 新概念

### 机械结构

机械结构包括车架、轮子、减速机构、支架和连接件。它决定机器人能承受多少重量、采用怎样的运动方式，以及传感器安装在什么位置。差速轮、麦克纳姆轮、全向轮和阿克曼转向结构的运动方式不同，后续控制方法也会不同。

### 电源

电池和电源模块为各部分提供电能。主控、传感器、电机驱动器可能使用不同的电压和电流。电源负责“让部件有条件工作”，但它不决定机器人往哪里走。

### 电机与电机驱动器

电机把电能变成机械运动。主控或控制板不能直接为大功率电机供电，因此通常由电机驱动器接收较小的控制信号，再调节流向电机的电流。减速电机还会通过齿轮降低转速、提高输出力矩。

### 传感器

传感器把现实世界的状态变成程序可以读取的数据。例如：

- 激光雷达测量周围物体的距离；
- 摄像头产生图像；
- 编码器记录车轮转动；
- 惯性传感器测量加速度和旋转情况。

传感器只是提供观测。它不会自动决定机器人应该左转、停车还是继续前进。

### 主控

主控是机器人上运行高层程序的计算机，可能是树莓派、Jetson、RDK、Atlas 或工控机。它会读取传感器数据，运行定位、导航和视觉程序，再产生运动目标。

可以暂时把主控理解为“负责思考和组织工作的电脑”。这个说法不意味着它像人一样思考，只是为了区分它和负责快速底层执行的控制板。

### 控制板

控制板通常靠近电机和底盘硬件。它按固定周期读取编码器、惯性传感器和其他底层信号，计算电机输出，并处理使能、停止和基本保护。WHEELTEC 底盘常见的控制板使用 STM32 系列微控制器，因此后文也会把它简称为 STM32 控制板。

主控擅长运行较复杂的软件，控制板擅长稳定、及时地处理底层输入输出。两者通过串口、CAN 等连接交换命令和反馈。

## 图示或逐步例子

以“前方出现纸箱，机器人减速”为例：

1. 激光雷达测到前方距离变小。
2. 主控中的避障或导航程序读取距离数据。
3. 程序计算出更低的目标速度。
4. 底盘相关程序把速度目标交给控制板。
5. 控制板根据目标速度和车轮反馈调整电机输出。
6. 电机转速下降，轮子带动车体减速。

如果第 2 步的程序运行正常，但控制板没有使能，前四步仍可能全部成功，轮子却不会转。这就是为什么“软件启动了”和“机器人能安全运动”是两个不同的判断。

## 可选实验

不用开机，观察手边机器人或产品照片，尝试找到：

- 车架和轮子；
- 电池或电源接口；
- 至少一种传感器；
- 主控；
- 底盘控制板；
- 电机和电机线。

不要为了看清部件而拔插线缆。暂时无法判断某块电路板的作用时，记录板上的型号或丝印，留到实机识别章节再确认。

## 本章小结

轮式机器人可以按“感知、计算、控制、执行”理解。传感器获取环境和自身状态，主控运行高层程序，控制板完成底层闭环与接口控制，电机和机械结构产生运动，电源为整条链路供能。

2. 主控与控制板的工作侧重点有什么不同？
