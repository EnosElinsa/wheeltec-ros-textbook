# 第一篇：从软件层认识 ROS 机器人

第一篇从软件层建立机器人系统的概览。读者先认识 ROS 与 ROS 2，再了解传感器、主控、控制板和执行机构在系统中的位置，随后进入 Ubuntu 终端，观察节点交换消息，并比较 ROS 2 的几种通信方式。硬件型号、接口电气条件和底盘控制放在第二篇展开。

## 学习方式

- 阅读与练习：根据正文、图示和代表性输出完成章末练习，适合先建立概念模型。
- 终端观察：在装有 ROS 2 的 Ubuntu 电脑或机器人主控上运行第 3、4 章的只读命令，观察系统信息和节点通信。

## 本篇内容

1. [第 1 章：认识 ROS 与 ROS 2](01-understanding-ros.md)：ROS 的全称、定位、发展和系统位置。
2. [第 2 章：一台 ROS 机器人如何工作](02-robot-system-overview.md)：传感器、主控、控制板和执行机构的分工。
3. [第 3 章：Ubuntu、终端与程序](03-ubuntu-terminal-programs.md)：操作系统、文件、进程和终端命令。
4. [第 4 章：第一次观察 ROS 2](04-first-ros2-observation.md)：运行示例并查看节点、话题和消息。
5. [第 5 章：ROS 2 程序怎样协作](05-ros2-communication.md)：节点、话题、服务、动作和参数。

完成这条知识链后，进入第二篇，从设备边界和控制关系继续学习硬件、接口、传感器与闭环控制。
