# 第一篇：从零认识 ROS 机器人

第一篇不要求你会用 Linux，也不要求机器人已经连接。我们先从一台轮式机器人的可见部件讲起，再认识电脑里的程序，最后观察几个 ROS 2 程序怎样交换消息。

## 两种学习方式

- **只读路线**：阅读正文、图示和示例输出，完成每章的自检问题。没有机器人、没有安装 ROS 2，也可以学完本篇。
- **可选实验路线**：如果手边有装好 ROS 2 的电脑或机器人主控，可以跟随第 2、4 章执行安全的观察命令。实验不控制电机。
