# 2. Ubuntu、终端与程序

## 本章要回答的问题

主控既然是一台计算机，它怎样管理文件、设备和正在运行的程序？教程里的“打开终端并执行命令”究竟是在做什么？

本章从普通电脑的使用经验出发。没有机器人也能阅读；可选命令只查看状态，不修改文件或系统设置。

## 从一个具体场景开始

在桌面系统中，我们通常点击图标启动应用。机器人主控也能这样工作，但开发和排障时更常使用终端，因为终端能准确显示执行了什么命令、程序返回了什么信息。

主控开机后，最先运行的是操作系统。操作系统负责管理处理器、内存、磁盘、网络和外接设备，其他程序在它提供的环境中运行。许多 WHEELTEC 主控使用 Ubuntu，它是一种 Linux 操作系统。

## 新概念

### 文件与目录

文件保存内容，例如程序、配置、地图或日志。目录用于组织文件，也可以包含下一级目录。你在图形文件管理器中看到的文件夹，在终端里通常称为目录。

目录形成一棵树。终端始终处在其中一个位置，这个位置叫当前工作目录。执行命令前先确认当前位置，可以避免在错误目录中查找或修改文件。

### 终端与命令

终端是输入文字命令、查看文字结果的窗口。命令是一条明确的操作请求，例如“显示当前位置”或“列出这里的文件”。按下回车后，终端把命令交给对应程序执行，再显示输出。

### 程序与进程

程序是保存在文件系统中的可执行内容。程序开始运行后，操作系统会为它创建一个进程。一个程序可以启动多次，因此同一个程序可能对应多个进程。

可以这样记：程序像一份保存在磁盘上的菜谱，进程像一次正在进行的烹饪。菜谱没有执行状态，正在烹饪的过程却会占用时间、工具和材料。

### 本地终端与远程终端

直接给主控连接显示器和键盘，可以打开本地终端。如果主控已经接入网络，也可以从另一台电脑通过 SSH 打开远程终端。SSH 只是安全地传输键盘输入和文字输出；远程终端里运行的程序仍在机器人主控上。

本章不要求使用 SSH。初学时用本地终端更直观，后续需要远程连接机器人时再配置网络。

## 图示或逐步例子

下面五条命令都只读取状态。每条命令先回答一个问题。

### 我现在位于哪个目录？

```bash
pwd
```

可能看到：

```text
/home/wheeltec
```

### 当前目录里有什么？

```bash
ls
```

可能看到若干文件和目录名称，例如 `Desktop`、`Documents`。

### 当前系统使用什么内核和硬件架构？

```bash
uname -a
```

输出会包含 Linux 内核版本和 `aarch64`、`x86_64` 等架构信息。

### 当前用户是谁？

```bash
whoami
```

输出是一行用户名。这个身份会影响你能否访问某些设备和文件。

### 系统中有哪些进程？

```bash
ps -e | head
```

输出前几行通常包含进程编号、终端和程序名称。这里看到的是正在运行的进程，不是磁盘中所有程序。

## 可选实验

如果手边有 Ubuntu 电脑或机器人主控，可以依次执行上面的五条命令，并把结果写成一张小表：

| 问题 | 命令 | 我的结果 |
|---|---|---|
| 当前目录 | `pwd` |  |
| 当前目录内容 | `ls` |  |
| 系统信息 | `uname -a` |  |
| 当前用户 | `whoami` |  |
| 运行中的进程 | `ps -e \| head` |  |

看不懂全部输出没有关系。先做到“知道自己问了什么”，再逐步理解字段。

## 本章小结

Ubuntu 是主控上的操作系统。文件保存内容，目录组织文件；终端接收命令并显示结果；程序保存在磁盘中，程序运行后成为进程。SSH 可以远程打开终端，但不会改变程序实际运行的位置。
