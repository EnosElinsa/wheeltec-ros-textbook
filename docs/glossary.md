# 术语表

本表统一教材中的中英文写法。首次出现的术语采用正式全称，后文使用表中约定的简称或中文名称。

| 术语 | 定义 | 主要章节 |
|---|---|---|
| 机器人操作系统（Robot Operating System, ROS） | 面向机器人软件开发的开源框架、工具和工程约定。 | 第 1 章 |
| 机器人操作系统 2（Robot Operating System 2, ROS 2） | ROS 的第二代平台，面向跨平台、复杂网络和工程部署场景。 | 第 1、4、5 章 |
| 操作系统（Operating System, OS） | 管理处理器、内存、文件、网络和设备资源的软件。 | 第 3 章 |
| 安全外壳协议（Secure Shell, SSH） | 为远程终端提供加密连接的协议。 | 第 3、9 章 |
| 控制器局域网（Controller Area Network, CAN） | 用于控制器之间可靠交换短报文的现场总线。 | 第 2、15 章 |
| 数据分发服务（Data Distribution Service, DDS） | ROS 2 使用的通信中间件标准，负责发现参与者并传递数据。 | 第 18、20 章 |
| 服务质量（Quality of Service, QoS） | 描述消息可靠性、持久性和时延等通信策略的配置。 | 第 20 章 |
| 统一机器人描述格式（Unified Robot Description Format, URDF） | 用 XML 描述机器人连杆、关节、几何外观和坐标关系的格式。 | 第 22 章 |
| 节点（Node） | 在 ROS 2 中承担一项明确工作的程序单元。 | 第 4、5、20 章 |
| 话题（Topic） | 节点之间传递连续数据的命名通道。 | 第 4、5、20 章 |
| 发布者（Publisher） | 向话题写入消息的节点接口。 | 第 4、5、20 章 |
| 订阅者（Subscriber） | 从话题读取消息的节点接口。 | 第 4、5、20 章 |
| 服务（Service） | 表示一次请求和一次响应的接口。 | 第 5、20 章 |
| 动作（Action） | 支持目标、反馈、结果和取消的耗时任务接口。 | 第 5、20、28 章 |
| 参数（Parameter） | 描述节点运行配置的键值。 | 第 5、21 章 |
| 工作空间（Workspace） | 组织源码、构建结果和安装文件的目录结构。 | 第 19 章 |
| 功能包（Package） | ROS 2 中可独立构建和分发的代码与资源单元。 | 第 19、20 章 |
| 主控 | 运行 Ubuntu、ROS 2 和上层应用的计算机。 | 第 2、3 章 |
| 底盘控制板 | 运行固件、采集反馈并执行电机控制的控制器。 | 第 2、33–37 章 |
| `cmd_vel` | 常见的机器人速度目标话题名称。 | 第 13、20 章 |
| `base_link` | 表示机器人主体的基础坐标系名称。 | 第 22、27 章 |
| `odom` | 表示局部连续里程计坐标系的名称。 | 第 16、27 章 |
| `map` | 建图和定位使用的全局坐标系名称。 | 第 27、28 章 |
| TF | ROS 中维护坐标系变换关系的机制。 | 第 22、27 章 |

若某个术语只在单个章节中出现，正文会直接给出中文含义，不为它额外引入缩写。
