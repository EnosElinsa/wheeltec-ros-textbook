# 术语表

| 术语 | 本书中的含义 |
|---|---|
| 主控 | 运行 Ubuntu、ROS 和上层应用的计算机，例如 Jetson、树莓派、RDK、Atlas 或工控机。 |
| 底盘控制板 | 运行 STM32 固件、直接控制电机并采集编码器和 IMU 的控制器。 |
| 底盘 | 控制板、电机、驱动器、轮组、机械结构和相关传感器组成的运动执行部分。 |
| 源码 | 可以修改并重新构建的 ROS 功能包或 STM32 工程。 |
| 固件 | 编译后写入底盘控制板的程序文件，常见格式为 `.hex` 或 `.bin`。 |
| 话题 | ROS 节点之间持续发布和订阅消息的通信通道。 |
| 参数 | 节点运行时读取的配置值。 |
| `cmd_vel` | 常见的机器人速度命令话题，消息通常使用 `geometry_msgs/Twist`。 |
| `odom` | 局部连续的里程计坐标系，也常指里程计消息或相关话题。 |
| `base_link` | 表示机器人主体的基础坐标系。 |
| `map` | 建图或定位系统使用的全局坐标系。 |
| TF | ROS 中维护坐标系之间时变或静态变换的机制。 |
| URDF | 描述机器人连杆、关节、外观和坐标关系的模型格式。 |
| 建图 | 根据传感器和位姿估计生成环境地图。英文资料常写作 mapping 或 SLAM。 |
| 定位 | 在已有地图中估计机器人当前位姿。 |
