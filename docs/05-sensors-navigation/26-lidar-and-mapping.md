# 26. 激光雷达与二维建图

## 26.1 学习目标

在雷达、里程计和 TF 已通过的前提下选择建图算法，生成可重复加载的二维地图，并保存建图时的参数与日志。

## 26.2 适用范围

单线二维雷达。多线雷达三维功能和视觉融合不属于本章主线。

## 26.3 操作前检查

- 第 25 章雷达扫描频率稳定。
- `odom → base_link → laser` TF 连续且方向正确。
- 轮径、轮距和里程计方向已核对。
- 场地允许低速完整覆盖。

## 26.4 工作原理

二维 SLAM 把雷达扫描与机器人运动估计配准，持续更新地图。Gmapping 依赖粒子滤波和较可靠里程计；slam_toolbox 是 ROS 2 常用方案，支持在线/离线与图优化；Cartographer 使用扫描匹配和图优化，对配置与算力更敏感。

算法不是越复杂越好。首次建图优先使用当前镜像已适配、日志清晰且能稳定闭环的方案。

## 26.5 操作步骤

1. 启动底盘、雷达和 TF，先在 RViz 看扫描是否贴合实物。
2. 选择一个建图 Launch，只运行一套 SLAM。
3. 低速沿场地边缘行驶，避免急转和长时间原地打滑。
4. 回到已走过区域，观察墙线能否重合，判断闭环和里程计质量。
5. 建图结束后停止运动，再用当前算法或 Nav2 提供的保存工具保存地图。
6. 记录 YAML/PGM 或序列化地图文件、分辨率、原点、算法和参数版本。

若使用历史 ROS 1 Bag 做离线诊断，先完成 [ROS 1 Bag 离线传感器诊断](../appendices/a-ros1-maintenance.md#ros1-bag-offline-diagnostics)，确认扫描类型、frame、TF、里程计和时间条件。只有扫描而没有 TF/里程计的 Bag 不能据此宣称建图条件完整。

## 26.6 验收标准

- 静止时地图不持续抖动或扩散。
- 同一墙面多次经过后基本重合。
- 地图比例和方向与场地一致。
- 保存文件可在新会话加载。
- 建图日志、算法和源码版本已归档。

## 26.7 故障排查

| 现象 | 优先检查 |
|---|---|
| 地图重影 | TF、雷达时间戳、里程计和打滑 |
| 地图旋转/倾斜 | 雷达安装方向和静态 TF |
| 转弯处撕裂 | 角速度过高、扫描频率或里程计误差 |
| 保存后空白 | 保存时机、地图话题和输出路径 |
