# 29. 多点导航、路径跟踪与自主探索 {#path-follow-code-resource}

## 29.1 学习目标

在单目标 Nav2 已通过后，增加任务层功能：按序访问多个目标、跟踪给定路径或自动选择探索目标。失败时仍回到 Nav2 基础链诊断。

## 29.2 适用范围

ROS 2 多点导航、路径跟踪和 RRT/前沿探索类功能。具体包和消息随资料版本变化。

## 29.3 操作前检查

- 第 28 章单目标导航稳定。
- 取消动作和急停已经验证。
- 地图边界与禁行区明确。

## 29.4 工作原理

多点导航管理一组目标及失败策略；路径跟踪给控制器一条离散路径；自主探索根据未知区域生成新目标。它们复用定位、代价地图和控制器，不应各自重复启动另一套底盘或 TF。

## 29.5 操作步骤

1. 多点导航先使用两个近距离目标，记录到达顺序、等待和失败策略。
2. 路径跟踪先检查路径坐标系、点间距和方向，再低速运行。
3. 自主探索设置地图边界、最小目标距离和停止条件，清除危险区域。
4. 运行时观察当前目标、动作反馈、全局路径和 `cmd_vel`。
5. 主动取消一次，确认任务层和底盘都停止。

## 29.6 验收标准

- 目标/路径坐标系与地图一致。
- 单个目标失败不会让任务无限重试或越界。
- 取消后不再产生非零速度。
- 探索结束条件明确，地图可保存。

## 29.7 故障排查

| 现象 | 处理 |
|---|---|
| 多点顺序混乱 | 查列表生成、坐标系和索引 |
| 路径偏离地图 | 查 frame_id、原点和路径转换 |
| 探索反复选同一点 | 查黑名单、前沿阈值和定位稳定性 |
| 取消后继续走 | 查动作取消、任务线程和速度发布者 |
