# 28. Nav2 导航 {#nav2-code-resource}

## 28.1 学习目标

在定位稳定后启动 Nav2，发送一个短距离目标，观察全局规划、局部控制、代价地图和恢复行为，并能定位失败属于哪一模块。

## 28.2 适用范围

ROS 2 Nav2 二维导航。不同镜像可能使用不同规划器和控制器插件。

## 28.3 操作前检查

- 第 27 章定位通过。
- 地图与实物环境基本一致。
- 急停可用，初次目标距离短且路线清空。
- 机器人 footprint、最大速度和传感器范围与实机匹配。

## 28.4 工作原理

### 规划、控制与恢复

全局代价地图在地图上规划较长路径，局部代价地图处理实时障碍；规划器给出路径，控制器生成速度，行为树协调导航、重试和恢复。目标失败不能只归结为“Nav2 参数不对”，应看具体生命周期节点和动作反馈。

## 28.5 操作步骤

### 启动与短距离验证

1. 启动地图、定位和 Nav2，确认生命周期节点为 active。
2. 在 RViz 检查全局/局部代价地图、footprint 和激光障碍。
3. 发送前方 0.5–1 m 的目标，准备急停。
4. 观察全局路径、局部轨迹、`cmd_vel` 和动作反馈。
5. 取消目标，确认机器人停止。
6. 放置安全障碍，检查局部代价地图更新和绕障/停止行为。
7. 只有基础链路稳定后才切换规划器或控制器，每次只改一个插件配置。

## 28.6 验收标准

- 所有必要生命周期节点 active。
- 全局路径落在可通行区域。
- 局部轨迹不穿过障碍和膨胀区。
- 到达、取消和失败后均可靠停止。
- 导航失败能对应到定位、地图、规划、控制或恢复模块。

## 28.7 故障排查

| 现象 | 优先检查 |
|---|---|
| 无全局路径 | 地图、目标位置、全局代价地图和规划器 |
| 有路径但不动 | 控制器、速度话题、底盘和生命周期状态 |
| 原地振荡 | footprint、局部代价地图、最小速度和里程计 |
| 擦碰障碍 | footprint、膨胀半径、雷达盲区和制动距离 |
| 到点不停 | 目标容差、控制器、速度复用和底盘停止链 |
