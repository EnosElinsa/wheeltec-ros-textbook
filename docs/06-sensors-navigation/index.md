# 第六篇：传感器、建图与导航

本篇从传感器产生的原始数据出发，沿着驱动、话题、坐标、地图、定位、规划和视觉处理逐层展开。建图和导航之前，先证明每个传感器、里程计和坐标变换都正常，不把“一键启动”当作验收结果。

## 学习顺序

```text
传感器与驱动
  → 里程计、TF 与时间
  → 建图与定位
  → 导航与路径任务
  → 相机与视觉应用
```

## 本篇内容

| 阶段 | 章节 | 要解决的问题 |
|---|---|---|
| 输入数据 | 第 29 章 | 常见传感器测量什么，底层数据怎样经驱动变成 ROS 2 消息和话题，如何逐层自检 |
| 里程计与坐标 | 第 30 章 | 里程计、TF 和时间信息从哪里来，建图前怎样验证输入链路 |
| 地图与坐标 | 第 31～32 章 | 怎样用雷达和里程计建图，怎样加载地图、定位并验证 TF 链 |
| 导航任务 | 第 33～34 章 | 怎样完成 Nav2 导航、多点任务、路径跟踪和自主探索 |
| 视觉数据 | 第 35～37 章 | 相机怎样发布图像，怎样标定，再怎样接入视觉跟随、巡线和目标跟踪 |

第 29 章给出的设备 → 节点 → 话题 → 通信匹配 → 时间检查链，以及第 30 章的里程计、TF 与时间检查，是后续每章排查输入问题时的共同起点。
