## 分类怎样进入正文

P28 将不同层次分别展开：§1.2 介绍闭环、重定位与跨机器人定位；§2 介绍地图组织；§3 按地点识别与位姿估计的衔接方式介绍四类单次观测流程；§4 讨论连续观测。正文据此先讲恢复任务，再讲保存哪些参考，随后讲怎样求出位姿。

P28 的三种地图组织形式分别是 keyframe-based submap、global feature map、global metric map。其 §2.3 中的 global metric map 特指集中保存的较稠密几何表示，包括点、栅格、体素与网格；特征地图和子地图也可以保存度量坐标。正文直接说明数据内容，并用关键帧、稀疏特征和整张几何地图解释各自需求。

P29 先区分二维参考与三维场景，再分别展开显式图像数据库、网络内的场景表示、局部描述子匹配与场景坐标回归。原文的二维参考包括带已知位姿的图像数据库。正文用实际保存的数据和求解步骤说明，避免将其与二维占用栅格混同。

正文开篇表格概括恢复所用的参考。后文分别说明数据组织、位姿计算与恢复范围；例如 AirSLAM 同时使用关键帧组织与稀疏三维几何。沿线子地图说明覆盖范围怎样随任务缩小，场景专用模型说明训练数据与模型参数怎样提供坐标参考，外部定位说明卫星、基站或标记测量怎样进入任务坐标系。

## 代表方法与实验事实

Reliable MCL、BEVPlace++、AirSLAM、AGLoc、BIM-Loc、FusedNet、DURAL 等方法沿用此前的[定向原文核查](relocalization-reference-audit.md)与[证据表](relocalization-evidence.csv)。连续观测与结果接受的具体实现仍按各论文分别核对；本章在 WHEELTEC 中提出的测试顺序属于待实车验证的工程安排。

Partsey 等的 P27 移至正文第 33.7 节。系统运行时使用连续 RGB-D 图像和已执行动作估计运动，更新出发时已给定的目标相对坐标，再用深度图像、相对目标与网络记忆选择动作。导航策略训练时使用仿真器提供的准确位置和朝向，测试时使用视觉里程计。运行流程没有地图匹配或外部定位恢复环节。

P27 的成功条件为距真实目标不超过 0.36 米时发出停止指令；Habitat Challenge 2021 仿真测试集成功率为 94%，实机初步实验共 9 次任务、成功率为 11%。设置、原文位置与文件哈希保留在[在线导航核查](online-navigation-reference-audit.md#pointgoal-odometry)及其证据表中。正文同时保留训练与运行输入、初始目标条件、仿真与实机结果。
