# 第 33 章地图依赖分类核查说明

本记录对应 2026 年 11 月 12 日按三条导航路线重写的[第 33 章](../33-relocalization-map-dependence.md)。[分类证据表](navigation-taxonomy-evidence.csv)保留原文位置、短引文和文件哈希。此前的[重定位核查](relocalization-reference-audit.md)与[在线导航核查](online-navigation-reference-audit.md)保留各自日期和范围。

## 分类依据与本章判据

DeSouza 与 Kak 的经典综述在室内视觉导航部分区分基于地图、基于建图和无地图三类。第 33 章借鉴这一框架，按已有地图依赖、在线空间建模和直接感知控制组织讲解。经典综述的原始范围与现代激光、视觉和学习系统并不完全一致，本章没有把三分法宣称为所有导航文献一致采用的严格标准。

为使具体比较互斥且完整，本章固定运行模式与空间模型含义，先判断是否依赖已有环境参考，再判断是否在线建立供定位或规划查询的空间模型。示教与复现阶段分别判断，论文模块与完整系统分别核对。地图表示、覆盖范围、全局一致性、位置来源和加载方式属于其他比较维度。

## 代表工作与结论的处理

FRTree 的自由区域树与 Active NTFields 的在线场景模型归入在线建模。当前扫描控制屏障函数在控制模块层面归入无显式地图，同时保留 Vicon 位置来源的实验条件。MTG、DTG 区分训练监督与运行输入，DTG 的完整系统还组合局部规划器，不能仅凭轨迹模块的输入给整个系统贴上无地图标签。

FusedNet 的场景坐标通过训练进入参数，归入已有场景参考。拓扑度量示教复现保留已有参考，却不要求一张全局一致的度量地图。由此，正文把“导航不必预建完整地图”与“全区域环境匹配恢复需要相应覆盖的参考”连接成条件明确的结论。

用户提供的无人机稿件先将扫描整理成局部高程栅格，再滚动优化路径，其机制属于在线局部建模。该稿件的公开出版身份尚未验证，本轮没有新增正式引文或采用其性能数字。FRTree 与 Active NTFields 已为相应机制提供可核查的正式来源。

本轮首先复用库内综述与已有方法证据。此前外部发现检索用于寻找分类原始出处，候选元数据不作为全文证据。Bonin-Font 等人的相关综述因官方访问受限未取得全文，也未用于支持本章结论。当前依据足以支撑此次教学编排，不代表完成了该领域的系统性文献综述。
