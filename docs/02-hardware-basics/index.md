# 第二篇：机器人硬件、接口与控制基础

第一篇从软件层概览了机器人系统。本篇进一步展开设备边界、接口、状态反馈和底盘控制，说明各部件负责什么、如何交换信息，以及这些关系怎样落到实际运动上。阅读顺序从设备分工开始，经过通信和反馈，最后进入运动控制；完成第 6～9 章后，继续第三篇的实机接入。

## 学习顺序

```text
设备分工 → 接口与通信 → 状态反馈 → 底盘运动与闭环控制
```

## 本篇内容

1. [第 6 章：主控、控制板与固件](06-controller-and-firmware.md)：明确计算设备、控制板、驱动器和固件的边界。
2. [第 7 章：电气接口与通信](07-electrical-interfaces-communication.md)：沿设备连接理解 USB、串口、UART、CAN、帧和校验。
3. [第 8 章：传感器与状态反馈](08-sensors-and-feedback.md)：说明编码器、IMU、OLED、激光雷达和时间坐标分别提供什么信息。
4. [第 9 章：底盘运动与闭环控制](09-chassis-motion-control.md)：把车型、轮速、里程计、PWM 和 PID 放进同一个控制关系。

完成本篇后，继续阅读[第三篇：实机接入与首次启动](../03-bringup/index.md)。
