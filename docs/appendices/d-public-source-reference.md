## 使用边界

- ROS 2 示例可按第 19、20 章的命令构建和运行。
- 其他代码包用于对应章节的阅读、修改或平台适配；使用前请核对 ROS 发行版、主控平台和包内接口。
- STM32 与 R680 代码涉及具体控制板和车型。实机照片补齐前，相关内容只作为代码资源；使用前先完成硬件核对，接线、运动和烧录仍以已核对的硬件为准。
