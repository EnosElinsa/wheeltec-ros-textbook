# B. 车型、主控与控制板矩阵

## 本章目标

用一张矩阵记录“哪套源码/固件适合哪台机器人”。矩阵中的空白不是默认兼容，必须回到随货清单、控制板丝印和当前工作空间核对。

## 通用判断顺序

1. 底盘运动形式。
2. 主控型号、Ubuntu 与 ROS 发行版。
3. STM32 控制板及硬件版本。
4. 编码器类型和电机数量。
5. 雷达、相机和其他选配。
6. 源码/固件版本日期。

## R680 控制板分支

| 控制板 | 适用说明 |
|---|---|
| C50C | 当前 R680 主线；仍需核对底盘和编码器 |
| C50B | 旧版维护；使用 C50B 专用工程和固件 |
| C50A | 更旧版本；不要套用 C50C 参数 |

## 置信度定义

- **资料核对**：来源文件、硬件标签和版本信息能够对应，但尚未在当前实机执行。
- **实机验证**：在当前机器人上完成启动、底盘和目标功能检查，并保存证据。
- **待核对**：缺少控制板、编码器、固件或随货信息，禁止据此烧录。
