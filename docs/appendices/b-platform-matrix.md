# B. 车型、主控与控制板矩阵

## 本章目标

用一张矩阵记录各台机器人的硬件、系统和源码/固件版本。填写时查看随货清单、控制板丝印和当前工作空间。

## 通用判断顺序

1. 底盘运动形式。
2. 主控型号、Ubuntu 与 ROS 发行版。
3. STM32 控制板及硬件版本。
4. 编码器类型和电机数量。
5. 雷达、相机和其他选配。
6. 源码/固件版本日期。

## R680 控制板分支

| 控制板 | 适用说明 |
|---|---|
| C50C | 当前 R680 主线；仍需核对底盘和编码器 |
| C50B | 旧版维护；使用 C50B 专用工程和固件 |
| C50A | 更旧版本；不要套用 C50C 参数 |

## 填写测试结果

填写测试日期、启动情况、底盘反馈和目标功能结果，并附日志或照片。发现固件与控制板、编码器不匹配时，先查明版本并准备原固件的恢复方法，再进行烧录。
