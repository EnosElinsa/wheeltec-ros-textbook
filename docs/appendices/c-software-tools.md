# C. 软件、驱动与工具索引

## 使用原则

先确认平台、操作系统和用途，再打开资源。驱动、烧录器和镜像工具可能改变系统或控制板状态，安装前保存当前环境。

## 常见工具

| 类别 | 用途 | 注意事项 |
|---|---|---|
| CH340/CH9102/CP2102 驱动 | USB 转串口识别 | 只安装与当前芯片和系统匹配的版本 |
| ST-Link/Keil 工具链 | STM32 构建和烧录 | 确认芯片、下载地址和工程版本 |
| 串口调试助手 | 查看/发送字节帧 | 使用十六进制模式，运动帧先失能 |
| CAN 分析器与 SocketCAN | 监听和发送 CAN 帧 | 核对 H/L、波特率和终端电阻 |
| VMware/Ubuntu | 虚拟机开发环境 | 检查 USB 和网络桥接 |
| Docker | 隔离 ROS 镜像 | 核对设备、GPU、网络和挂载 |
| SD/镜像工具 | 系统备份与恢复 | 先验证备份可读，不覆盖唯一副本 |

## 使用安全

安装驱动或烧录工具前，先记录操作系统版本、控制板型号和当前可用状态。分享日志前删除密码、令牌、序列号和个人网络信息。
