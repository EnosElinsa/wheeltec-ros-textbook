# 12. 遥控底盘：APP、PS2 与航模遥控

## 12.1 学习目标

不经过 ROS，先验证电池、控制板、驱动器、电机和机械结构。遥控测试通过后，ROS 控制失败的排查范围会缩小到主控通信和软件配置。

## 12.2 适用范围

| 遥控方式 | 适合用途 | 接入特点 |
|---|---|---|
| 蓝牙 APP | 读取部分参数、低速测试、部分车型纠偏 | 依赖蓝牙模块和对应 APP |
| PS2/USB 手柄 | 日常底盘验收 | 有线、无线和旧版接口不同 |
| 航模遥控 | 大底盘、较远距离和多通道控制 | 必须核对通道、失控保护和油门零位 |

具体按键会随遥控器和固件版本变化，正文只给出安全的验证流程。

## 12.3 操作前检查

!!! warning "第一次测试使用最低速度"
    清空场地，准备急停。航模遥控先让油门回到最低，PS2 确认模拟模式，APP 先确认连接的是当前机器人。

- 底盘自检通过。
- 底盘类型与遥控器设置一致。
- 接收机供电和信号线按对应控制板资料连接。
- 不启用导航、跟随或其他会发布速度的 ROS 节点。

## 12.4 工作原理

遥控器把摇杆或按键转换为底盘速度目标，STM32 直接接收并进入运动控制。它绕过 ROS 主控，因此特别适合区分“底盘硬件问题”和“ROS 问题”。

全向底盘可把左摇杆二维输入映射到 `v_x/v_y`，右摇杆控制旋转。差速、四驱和履带没有横移自由度。阿克曼通常需要前进/后退与转向同时输入。

## 12.5 操作步骤

### 1. 确认接收与控制模式

连接遥控器后，先看接收机指示灯和 OLED 控制模式。航模接收机常亮通常表示已对码；R680 OLED 应显示相应控制模式和目标值。没有模式变化时先查配对、接口和操作方式，不拆电机。

### 2. 做停止测试

在轮子架空或场地安全时，只接通遥控，保持摇杆中位。机器人不应持续运动。然后触发停止键、急停或失控保护，确认目标速度归零。

航模遥控必须配置失控保护。接收机失去信号时，油门通道应回到安全值；持续保持上一次命令会让底盘继续运动。

### 3. 逐方向低速测试

按前、后、左转、右转顺序测试。麦轮和全向轮再增加左右横移。每次输入不超过 1 秒，观察：

- OLED 模式和目标值是否改变；
- 轮子是否按底盘类型运动；
- 松开后是否立即停止；
- 编码器实际值是否跟随目标值；
- 是否有卡滞、打滑或异常噪声。

### 4. 单独处理遥控器差异

- PS2 有线手柄可能需要按 `ANALOG` 进入模拟模式。
- 航模遥控开机时油门不在最低位，会触发报警并禁止正常输出。
- 航模通道反向、混控或行程设置错误，会让动作与手册不一致。
- APP 中的参数写入会改变底盘状态。首次验收只读取，除非已备份原值。

## 12.6 验收标准

- 遥控器能进入明确控制模式。
- 停止、断开或失控保护能可靠归零。
- 支持的每个方向与实际动作一致。
- 不支持横移的车型没有被强行测试横移。
- OLED 目标值、编码器反馈和机械动作能够互相印证。

## 12.7 故障排查

| 现象 | 优先检查 |
|---|---|
| 接收机灯闪烁 | 未对码、信号丢失或供电不稳 |
| 模式不切换 | 接口、配对、激活操作或控制板固件 |
| OLED 有目标值，电机不动 | 使能、驱动器、电机、编码器自检 |
| 方向相反 | 通道反向、车型配置或电机/编码器方向 |
| 松手后继续运动 | 中位偏置、失控保护或接收数据未归零；立即停机 |
