# 17. 直线纠偏、转向标定和常见底盘故障

## 本章目标

先区分机械、接线、编码器、车型参数和软件偏置，再决定是否使用纠偏系数或调整阿克曼转向。避免用一个参数掩盖硬件故障。

## 适用范围

- 软件纠偏适用于电机个体差异或装配差异造成的持续直线偏移。
- 它不适合处理起步瞬间偏移、轮子装反、编码器故障、地面打滑或阿克曼前轮明显歪斜。
- R680 资料中的纠偏范围和方向只适用于相应固件版本。

## 开始前检查

1. 轮胎气压/磨损、紧固件、轴承和转向连杆无明显异常。
2. 左右轮径、编码器方向和目标/实测速度正确。
3. 选择平整、附着一致、足够长的测试场地。
4. 记录当前纠偏值、舵机零位、车型 TYPE 和固件日期。
5. 调机械或电位器前断电并标记原位置。

## 工作原理

持续直线偏移常来自两类误差：左右驱动能力不同，或几何方向本身不正。差速/四驱底盘可以用小的左右速度比例补偿第一类误差；阿克曼底盘若前轮中位不正，应先调整舵机零位或连杆，不能只靠左右轮速掩盖。

R680 纠偏资料中的系数以 50 为中值，范围 0–100：增大使底盘向右纠偏，减小使底盘向左纠偏。这个方向必须在自己的固件上用小步长验证。

闭环阿克曼转向还使用滑轨电位器反馈前轮位置。资料建议在断开舵机电源、手动摆动前轮时观察 `SLID` 变化；最大最小差距不足预期可能表示接触或电位器异常。

## 操作步骤

### 1. 给偏移分类

用低速直行 2–3 次，记录轨迹：

- 每次都向同一侧缓慢偏：可能适合纠偏。
- 起步偏、稳定后正常：先查死区、积分和负载。
- 方向随机：查地面、接触、松动和通信。
- 阿克曼始终斜行：先看前轮中位、舵机和连杆。
- 某轮实测速度为 0 或符号异常：先修编码器。

### 2. 比较目标与实测速度

架空和落地各测一次。目标相同但某轮测量值明显偏低，先查机械阻力、电机、驱动器和编码器。所有测量都合理而落地持续偏移，再考虑软件补偿。

### 3. 调整软件纠偏

1. 读取并保存当前系数。
2. 每次只调整一个小步长。
3. 相同速度、距离和地面重复测试。
4. 底盘向左偏时，资料版本建议适当增大系数；向右偏时适当减小。
5. 找到可接受范围后重启，确认参数持久化。

不要为了追求一次完全笔直而大幅来回调整。评价应基于多次重复结果。

### 4. 标定阿克曼中位

先确认车型 TYPE 正确。观察上电回正后左右前轮：

- 开环结构由舵机和机械连杆决定中位；
- 闭环结构还要确认滑轨电位器反馈随转向平滑变化；
- 前轮轻微偏差可按对应板卡资料调整舵机零位；
- 左右连杆长度不一致或结构变形时，先做机械修正。

不要在舵机持续顶住机械限位时继续通电，这会导致发热和齿轮损伤。

### 5. 处理自组或更换电机后的底盘

重新核对轮径、轮距、轴距、减速比、编码器类型、每转计数和电机方向。更换一个电机后，不能默认它与旧电机的编码器相位和性能完全相同。

## 结果验收

- 能明确说明偏移属于持续、起步、随机还是转向中位问题。
- 调整前后的参数、场地、速度和轨迹都有记录。
- 软件纠偏未被用来掩盖编码器或机械故障。
- 阿克曼前轮中位、左右极限和反馈变化正常。
- 重启后参数保持，低速和常用速度都没有明显副作用。

## 常见故障与处理

| 现象 | 优先处理 |
|---|---|
| 纠偏越调越严重 | 恢复原值，确认方向和固件版本 |
| 架空正常、落地偏差大 | 轮胎、负载、地面摩擦、机械阻力 |
| 阿克曼舵机抖动 | 反馈电位器、接线、零位或控制参数 |
| 前轮能转但不回正 | 舵机零位、连杆长度、车型设置 |
| OLED 目标有值、某轮实际为 0 | 编码器、电机或驱动器故障 |
| 自检显示 `TYPE X` | 先查车型、接线、编码器和电源，不做纠偏 |
