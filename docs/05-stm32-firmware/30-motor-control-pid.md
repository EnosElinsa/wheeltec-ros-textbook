# 30. 电机控制与 PID 实现

## 本章目标

从编码器计数得到轮速，理解增量 PI 怎样更新 PWM，并用曲线而不是听感调整参数。

## 适用范围

直流编码器电机速度环；舵机位置环和速度/位置串级控制采用同一误差反馈思路，但参数与输出不同。

## 开始前检查

- 编码器方向、每转计数、减速比和轮径正确。
- 电机架空测试可靠，PWM 限幅存在。
- 备份当前参数和固件。

## 工作原理

目标轮速来自逆运动学，测量轮速来自编码器。增量 PI 常写为：

$$
u_k=u_{k-1}+K_p(e_k-e_{k-1})+K_i e_k
$$

比例项影响对误差变化的响应，积分项消除持续误差。控制周期改变后，同一组参数不再等效。输出限幅、死区和失能时积分清零同样重要。

## 操作步骤

1. 用固定周期记录目标速度、测量速度、误差和 PWM。
2. 先确认开环方向和编码器反馈方向一致。
3. 从保守参数开始做小阶跃，不在满负载下首次调参。
4. 响应太慢时小幅增加比例；稳定误差明显时再增加积分。
5. 出现持续振荡、噪声或过冲时回退参数，检查采样和机械问题。
6. 测试停止、反向、低速和常用负载。
7. 每次参数变更保存曲线和版本。

## 结果验收

- 各轮响应方向正确，目标和实测曲线可解释。
- 常用速度下稳定误差可接受，无持续振荡。
- 停止和失能后 PWM、积分状态安全归零。
- 电机和驱动器温升正常。
- 参数在重启后按预期加载。

## 常见故障与处理

| 现象 | 优先检查 |
|---|---|
| 参数很小仍振荡 | 编码器方向、采样周期、机械间隙 |
| 低速长期不动后突然冲出 | 死区和积分饱和 |
| 左右轮参数差异很大 | 电机、驱动、轮胎和负载差异 |
| PWM 饱和仍达不到速度 | 供电、负载、减速比或目标不现实 |
