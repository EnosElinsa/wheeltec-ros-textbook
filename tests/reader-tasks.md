# Reader task test prompts

These prompts define the minimum discoverability check for the finished textbook:

1. 我刚收到机器人，如何确认车型、主控、控制板和 ROS 版本？
2. 第一次上电前要检查什么，正常基线是什么？
3. 机器人不动时，如何判断是遥控、STM32、通信还是 ROS 问题？
4. 如何检查底盘、IMU、雷达和相机话题是否正常？
5. 如何完成 ROS 2 建图、保存地图、定位和 Nav2 导航？
6. 如何安全修改一项机器人配置并回滚？
7. R680 如何选择正确控制板、编码器版本的源码和固件？
8. 升级失败后，应按什么顺序恢复配置、固件、源码和系统镜像？
